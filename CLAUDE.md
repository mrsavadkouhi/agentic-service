# Repository guidance

Read [AGENTS.md](AGENTS.md), the [shared agent index](.agents/README.md), and the
[architecture overview](.agents/architecture/overview.md) first. Follow the
[diagnostic agent](.agents/diagnostic-agent.md) for symptoms and investigations,
or the [developer agent](.agents/developer-agent.md) for changes and design.
Mixed work starts with diagnosis and updates both mandatory records.

These are tool-independent instructions. Canonical facts live in
[cross-file facts](.agents/architecture/cross-file-facts.md); existing policy and
operational sources are linked from the shared index. Root repository authority,
write restrictions and explicit-request commit policy continue to apply.
